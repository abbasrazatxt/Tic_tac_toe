# Tic-Tac-Toe Game

A simple and fun **Python console game** made for my **ICT Lab Final Project**.
This project is a two-player Tic-Tac-Toe game where players choose symbols, play turns, and try to win by completing a row, column, or diagonal.

## What This Game Does

* Takes names of both players
* Lets players choose `X` or `O`
* Uses a coin toss to decide the first turn
* Shows a clean 3x3 game board
* Takes input from 1 to 9
* Checks win and draw automatically
* Allows players to restart the game

## Files

```text
Game.py   → Main game logic
Grid.py   → Prints the game board
Toss.py   → Handles the coin toss
```

## How to Run

Open the project folder in terminal and run:

```bash
python Game.py
```

## Board Positions

```text
1 | 2 | 3
---------
4 | 5 | 6
---------
7 | 8 | 9
```

Choose a number to place your symbol in that position.
